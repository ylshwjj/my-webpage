🛠️ 如何將本網頁發布至 GitHub Pages (github.io)

  1. 在 GitHub 上建立一個公開儲存庫（Repository），名稱設定為 username.github.io（將 username 換成你的帳號）。
  2. 將本頁面的程式碼複製並儲存為 index.html。
  3. 使用 Git 指令將 index.html 上傳（Push）至 GitHub 儲存庫： 
    git add index.html
git commit -m "Initial commit - add website page"
git push origin main
  4. 前往 Repository 的 Settings > Pages，確認 Build and deployment 來源設定為 Deploy from a branch（選擇 main 分支）。
  5. 等待約 1-2 分鐘後，即可透過瀏覽器存取 https://username.github.io 觀看網頁！
